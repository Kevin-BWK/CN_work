# 1 安装与启动

## 1.1 环境要求

- Windows 10/11 64 位；
- 已安装 Npcap 1.10 或更高版本（安装时勾选 “Install Npcap in WinPcap API-compatible Mode”）；
- 无需安装 Python，发布目录已包含运行库。

## 1.2 启动

解压发布目录后双击 `FlowLens.exe`。整个 `FlowLens` 目录必须一起复制，不能只复制 exe 文件。

首次启动会自动枚举网卡；如果列表为空，请检查 Npcap 是否安装、网卡是否启用。

# 2 界面说明

- **控制栏**：网卡选择、BPF 过滤、开始抓包、停止、打开文件、导出 pcapng、运行时长；
- **实时报文表**：序号、时间、源/目的 MAC、类型、源/目的 IP、协议、长度、概要；解析失败的报文以红色显示；
- **字段详情**：按 Frame、Ethernet II、IPv4/IPv6、TCP/UDP 分层展示，缺失字段显示 N/A；
- **会话概览**：报文总数、解析成功/错误、IPv4/IPv6/其它、累计字节、当前速率、进程 CPU 与内存；
- **图表**：长度折线图、长度分段柱状图、协议分类柱状图；
- **状态栏**：左侧是当前状态或最近错误，右侧显示记录目录、队列与丢弃计数。

# 3 操作步骤

1. 在“网卡”下拉框选择要抓包的接口；
2. 如需过滤，在“BPF 过滤”填写表达式，例如 `tcp port 443`；留空表示不过滤；
3. 点击“开始抓包”，表格与图表开始刷新，运行时长开始计时；
4. 单击任意一行，下方显示该报文的各层字段；
5. 点击“停止”结束抓包，程序会关闭 pcapng 文件并写入 `session.json`；
6. 点击“导出 pcapng”可把多个分段合并成一个文件；
7. 点击“打开文件”可回读 pcap/pcapng，界面进入文件回放模式。

# 4 数据文件

会话目录位于程序所在目录的 `data/sessions/<年月日_时分秒>/`：

| 文件 | 内容 |
| --- | --- |
| `capture_*.pcapng` | 原始报文，按 256 MiB 自动分段 |
| `session.json` | 开始/结束时间、接口、BPF、版本、分段列表 |
| `resources.csv` | 每 10 秒一行资源与会话计数 |

`resources.csv` 字段：`timestamp,uptime_seconds,cpu_percent,rss_mb,disk_write_mb,system_memory_percent,disk_free_mb,captured,parsed,parse_errors,queue_dropped,record_dropped`。

# 5 常见问题

- **点开始后没有报文**：确认网卡选对、BPF 表达式没有写错、系统有实际流量；无线网卡只能看到本机进出的流量。
- **提示抓包线程未能启动**：检查 Npcap 是否安装、是否以管理员权限运行、网卡是否被其他抓包软件占用。
- **提示磁盘余量不足**：记录会停止、统计继续；清理磁盘后重新开始会话即可。
- **画面卡顿**：关闭其他占用 CPU 的程序；长时间运行时建议保持窗口可见但不要最小化到托盘。
- **导出失败**：目标磁盘空间不足或文件被占用；换一个目录再试。
- **云主机或远程桌面**：断开远程桌面连接后程序继续运行，但请勿注销会话。
